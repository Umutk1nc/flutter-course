# Flutter Course

My Flutter learning journey — building on the Dart foundation from my previous course.

This repository contains my notes, exercises, and projects while learning Flutter app development.

## Background

Before starting Flutter, I completed a Dart programming course covering fundamentals, OOP, null safety, generics, and asynchronous programming. This repo picks up from there and applies those concepts to building real Flutter applications.

## Course

- BTK Academy - Mobil Application Development with Flutter

## Goals

- Learn Flutter widgets, layouts, and state management
- Build multiple small apps to practice core concepts
- Understand the Flutter app lifecycle and navigation
- Get comfortable with async data, APIs, and local storage in Flutter
